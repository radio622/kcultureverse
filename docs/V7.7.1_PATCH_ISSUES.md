## Issue 5: 🚨 신해철 과집중 — 221개 엣지 중 219개가 허위 (확인 완료)

**증상**: 신해철이 degree=217로 우주에서 가장 큰 별 중 하나. 혁오·페퍼톤스·브로콜리너마저·검정치마 등 신해철과 실제 음악적 관계가 없는 아티스트들까지 연결됨.

**확인된 팩트**:

| 연결 유형 | 건수 | 비율 |
|---|---|---|
| GENRE_OVERLAP (플레이리스트 앵커) | **219개** | **99.1%** |
| 실제 크레딧 기반 (INDIRECT) | 2개 | 0.9% |

→ 신해철의 221개 관계 중 **219개가 "같은 플레이리스트에 있었다"는 이유 하나로** 생성됨.

**발생 경위** (`v6.4-batch-ingest-csvs.ts` 74~83행):
```typescript
const PLAYLIST_ANCHORS = {
  "Korean_Rock_Best_Songs_🇰🇷_(한국_락_마스터피스).csv": "신해철",  // ← 이 줄
  ...
};
```
→ `Korean_Rock_Best_Songs.csv`의 아티스트 전원이 `GENRE_OVERLAP, weight: 0.5`로 신해철에 연결됨.
→ 그 외 CSV들도 동일 패턴으로 각 앵커에 연결. 혁오가 신해철과 같은 관계 강도(0.5)로 묶임.

## Issue 7: 🚨 GENRE_OVERLAP 엣지 전면 재검토 — 전체 그래프의 48.8%가 오염

**확인된 팩트**:

| 지표 | 수치 |
|---|---|
| organic-graph.json 전체 엣지 | 8,636개 |
| GENRE_OVERLAP 엣지 | **4,214개 (48.8%)** |
| 크레딧 기반 엣지 (나머지) | 4,422개 (51.2%) |

GENRE_OVERLAP 4,214개의 출처:

| label | 건수 | 출처 |
|---|---|---|
| `장르 유사성` | 3,830개 | `v7.4-expand-universe.py`의 accent 색상 매칭 (weight=0.15) |
| `같은 플레이리스트 (라디오/모음집)` | **214개** | `v6.4` CSV 앵커 시스템 (weight=**0.5**) |
| `K-Rock 마스터피스 흐름` | 84개 | `v6.4` CSV 앵커 (weight=0.5~0.6) |
| `포크/인디 감성 영감 교류` | 55개 | `v6.4` CSV 앵커 (weight=0.5~0.6) |
| `라디오/명곡 앨범 동창` | 31개 | `v6.4` CSV 앵커 (weight=0.5~0.6) |

**문제의 핵심**: "같은 플레이리스트에 있었다" = weight **0.5**. 이것은 COMPOSER(작곡) 관계와 **동등한 수치**. Spotify 플레이리스트 하나에 같이 들어갔다고 실제 음악적 관계가 있다는 근거가 없음.

**수정 계획**:
- [ ] 플레이리스트 앵커 엣지(384개) 전량 삭제 또는 weight를 0.05 이하로 대폭 하향
- [ ] 장르 유사성 3,830개: weight 0.15는 수용 가능하나 재검증 필요
- [ ] 앵커 시스템 자체 재설계: 단일 앵커 방사형 → 플레이리스트 내 인접곡 체인으로 교체
- [ ] build 단계에서 GENRE_OVERLAP → INDIRECT 무분별 매핑 폐기 (relation 타입 보존)
